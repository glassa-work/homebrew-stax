# Homebrew tap — Stax

Homebrew tap for **Stax** — your codebase's knowledge brain.

## Install

```sh
brew tap glassa-work/stax
brew install stax              # CLI
brew install --cask stax      # desktop viewer (macOS)
```

…or in one shot: `brew install glassa-work/stax/stax`.

## What's here

- **`Formula/stax.rb`** — the CLI formula, **auto-generated by GoReleaser** on each
  release of the (private) source repo. It appears after the first `v*` tag is
  pushed; until then `brew install stax` reports "no available formula".
- **`Casks/stax.rb`** — the desktop viewer cask (notarized `.dmg`). Installs
  `Stax.app` and symlinks the bundled `stax` CLI onto your `PATH` via the cask
  `binary` stanza. Pending the first notarized desktop release.

No source lives here — just install manifests. The public release **binaries** are
published as assets on this repo by CI; the source stays in the private
`glassa-work/stax` repo.
